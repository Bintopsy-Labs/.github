Bintopsy develops **static analysis, deobfuscation, and program reconstruction** tooling for native code, bytecode, interpreters, and virtual machines.

We research and work with obfuscation in enterprise and open-source VMs, as well as VM and non-VM-based binaries and interpreted programming languages.

Most of our tooling is developed privately, with selected projects being released publicly.
